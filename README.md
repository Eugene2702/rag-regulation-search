# RAG Regulations Search

Pet-проект: система поиска и генерации ответов по внутренним регламентам (RAG) с поддержкой контроля доступа (ACL).

## Стек технологий

- **Backend:** Python, FastAPI, Uvicorn
- **Vector DB:** Qdrant (в Docker)
- **LLM:** Ollama (локальный inference, модель Qwen2.5)
- **Embeddings:** `intfloat/multilingual-e5-base` (768 dim)
- **Контейнеризация:** Docker, Docker Compose

## Архитектура

1. **Ingestion (`app/ingest_test.py`):** Загрузка документов, рекурсивный чанкинг (с учетом лимита 512 токенов), генерация эмбеддингов, сохранение в Qdrant с метаданными (`doc_id`, `acl`).
2. **Retrieval (`/search`):** Поиск по смыслу (cosine similarity). Фильтрация по ACL (пре-фильтрация в Qdrant) — пользователь не увидит документы, к которым у него нет доступа.
3. **Generation (`/ask`):** Retrieval + сборка промпта + генерация ответа через локальную LLM с возможностью корректного отказа (correct refusal).

## Метрики (на тестовом наборе из 30 вопросов)

- **Hit@5:** 100% (20 из 20) — правильный чанк найден в топ-5.
- **Correct Refusal:** 90% (9 из 10) — модель честно отказывается, если ответа нет.
  *(Примечание: 1 вопрос был помечен как галлюцинация из-за синонимичного отказа модели "не соответствует контексту", фактической галлюцинации не было).*
